# Дом книги

Учебный многостраничный каталог библиотеки, выполненный по трём лабораторным работам. Интерфейс использует HTML, CSS и JavaScript; Express отдаёт страницы и REST API с одного адреса; PostgreSQL хранит книги и категории.

## Страницы

- `public/index.html` — главная страница с подборкой книг из базы.
- `public/catalog.html` — каталог с поиском по названию и фильтром по категории.
- `public/item.html?id=1` — карточка одной книги.
- `public/add.html` — форма добавления книги.

## Технологии

HTML5, CSS Grid и Flexbox, адаптивные медиазапросы, JavaScript modules, Fetch API, Node.js 18+, Express 5, PostgreSQL и `pg`.

## Локальный запуск

1. Установите Node.js 18 или новее и PostgreSQL.
2. Создайте пустую базу данных, например `library_db`.
3. Выполните SQL-схему из корня проекта:

   ```sh
   psql -d library_db -f sql/schema.sql
   ```

4. Скопируйте `.env.example` в `.env` и укажите пользователя и пароль PostgreSQL в `DATABASE_URL`.
5. Установите зависимости и запустите сервер:

   ```sh
   npm install
   npm start
   ```

6. Откройте <http://localhost:3000>.

SQL-файл создаёт связанные таблицы `categories` и `items`, три категории и шесть книг. Повторное выполнение не добавляет дубликаты начальных записей.

## REST API

| Метод и адрес | Успешный ответ | Ошибка |
| --- | --- | --- |
| `GET /api/categories` | `200`, массив категорий | `500` при ошибке БД |
| `GET /api/items` | `200`, книги с названием категории | `500` при ошибке БД |
| `GET /api/items/:id` | `200`, одна книга | `400` для неверного id, `404` если книги нет |
| `POST /api/items` | `201`, созданная книга | `400` при неверных полях или категории, `500` при ошибке БД |

Пример тела запроса `POST /api/items`:

```json
{
  "title": "Левша",
  "author": "Николай Лесков",
  "description": "История тульского мастера и его необыкновенной работы.",
  "year": 1881,
  "categoryId": 1
}
```

Значения пользовательского ввода передаются PostgreSQL через параметры `$1`–`$5`. Сервер проверяет поля и существование категории. Соединение хранится в `.env`; файл `.env` исключён из Git.

## Проверка запросов в Postman

Создайте переменную `baseUrl` со значением `http://localhost:3000` и выполните:

1. `GET {{baseUrl}}/api/items` — ожидается `200` и список из PostgreSQL.
2. `GET {{baseUrl}}/api/items/1` — ожидается `200`; `GET {{baseUrl}}/api/items/99999` — `404`.
3. `POST {{baseUrl}}/api/items` с корректным JSON из примера — `201` и новый `id`.
4. Повторите POST с пустым `title` или несуществующим `categoryId` — ожидается `400`.
5. Перезапустите сервер и снова выполните GET списка: запись должна сохраниться в PostgreSQL.
