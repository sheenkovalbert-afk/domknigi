# Отчёт по лабораторным работам

## Тема и назначение

«Дом книги» — каталог художественной литературы. Посетитель просматривает книги, ищет их по названию, фильтрует по категории и добавляет новую запись через форму. Проект объединяет темы лекций: HTML/CSS, интерактивность JavaScript/DOM, REST API и постоянное хранение в PostgreSQL.

## Страницы и функции

| Страница | Реализация |
| --- | --- |
| Главная | Описание библиотеки и подборка книг, загружаемая через API. |
| Каталог | Карточки создаются через DOM; поиск нечувствителен к регистру; поиск и фильтр категории применяются одновременно; пустой результат сопровождается сообщением. |
| Карточка книги | Идентификатор берётся из URL; загружается `GET /api/items/:id`; обработаны отсутствующий и неизвестный id. |
| Добавление | Подписанные HTML-поля и проверки; обработчик `submit` отправляет JSON; успешный ответ показывает подтверждение и карточку новой записи. |

Ключевые функции JavaScript: `getJson` проверяет `response.ok`; `createBookCard` безопасно строит карточку с `createElement` и `textContent`; `coverForCategory` выбирает локальную обложку; `renderFilteredBooks` сочетает поиск по названию и фильтрацию по категории. Для запросов предусмотрены сообщения загрузки, ошибок и отсутствия результатов.

## Схема данных

```text
categories
  id   PRIMARY KEY
  name UNIQUE NOT NULL
       1 ─── много
items
  id           PRIMARY KEY
  title        NOT NULL
  author       NOT NULL
  description  NOT NULL
  year         NOT NULL, CHECK (1500–2100)
  category_id  FOREIGN KEY → categories.id
```

`sql/schema.sql` создаёт две связанные таблицы, три категории и шесть начальных книг. `JOIN` возвращает название категории вместе с книгой. Подключение задаётся локально в `.env`, секреты не включены в репозиторий.

## REST API

| Запрос | Назначение | Ожидаемый статус |
| --- | --- | --- |
| `GET /api/categories` | Список категорий | 200 |
| `GET /api/items` | Каталог с названием категории | 200 |
| `GET /api/items/:id` | Одна книга | 200 или 404 |
| `POST /api/items` | Создание книги | 201 или 400 при неверных данных |

Значения пользовательского ввода передаются SQL параметрами. Сервер отдельно проверяет название, автора, описание, год и наличие категории.

## Запуск и Git

Создать базу `library_db`, выполнить `psql -d library_db -f sql/schema.sql`, скопировать `.env.example` в `.env`, задать `DATABASE_URL`, затем выполнить `npm install` и `npm start`. Сайт откроется на `http://localhost:3000`. В локальной Git-истории — пять содержательных этапов: HTML, стили, интерактивность, сервер и база, документация.

## Результаты проверки

В README перечислены Postman-сценарии для списка, существующего и отсутствующего id, корректного и ошибочного POST, а также проверки сохранения после перезапуска. Фактическое подключение к PostgreSQL, запросы Postman и снимки экрана в этом окружении не выполнялись; поэтому коды выше являются ожидаемыми, а не зафиксированными результатами запуска. Для итоговой демонстрации выполните сценарии из README и добавьте 2–3 снимка главной страницы, каталога и формы.
